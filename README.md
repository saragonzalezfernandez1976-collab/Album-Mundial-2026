# 🏆 Album Mundial 2026

Aplicación interactiva para controlar y gestionar tus cromos del Mundial 2026.

## Características

- ✅ Gestión completa de cromos
- ✅ Seguimiento por selección nacional
- ✅ Estadísticas y progreso
- ✅ Sincronización en navegador
- ✅ Interfaz intuitiva y responsive

## Cómo usar

1. Abre `index.html` en tu navegador
2. Agrega cromos a tu colección
3. Marca los duplicados
4. Visualiza tu progreso

## Estructura

```
├── index.html          # Página principal
├── styles.css         # Estilos
├── app.js             # Lógica de la aplicación
├── data/
│   └── teams.json     # Datos de selecciones
└── README.md
```
